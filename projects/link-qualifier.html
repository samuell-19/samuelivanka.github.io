Case Study

iGaming Link Building Qualifier iGaming Link Building Qualifier

A browser-based tool that takes an Ahrefs Batch Analysis export and automatically scores every domain against the qualification criteria I developed over 4+ years of ordering links for iGaming clients — flagging PBN signals, link balance problems, and geo mismatches before they cost money.

Et browserbaseret værktøj, der tager et Ahrefs Batch Analysis-eksport og automatisk scorer hvert domæne op mod de kvalifikationskriterier, jeg har udviklet over 4+ års erfaring med at bestille links til iGaming-kunder — og flagger PBN-signaler, link balance-problemer og geo-mismatches, inden de koster penge.

Built for the iGaming vertical, but the scoring criteria are fully editable — adjustable to any niche or link building standard.

Bygget til iGaming-vertikalen, men scoreringskriterierne er fuldt redigerbare og kan tilpasses enhver niche eller link building-standard.

Why I built it Hvorfor jeg byggede det

When you order links through a broker, you receive a list of domains — sometimes 30, sometimes 100. Qualifying each one manually means opening Ahrefs for every domain, checking the traffic graph, calculating the dofollow ratio from the referring domains breakdown, looking at the outgoing link balance, and making a judgement call on whether the profile looks natural. For a list of 20 domains that's 2–3 hours of repetitive work.

Når du bestiller links via en broker, modtager du en liste over domæner — nogle gange 30, nogle gange 100. At kvalificere hvert domæne manuelt betyder at åbne Ahrefs for hvert domæne, tjekke trafikgrafen, beregne dofollow-ratio fra referring domains, kigge på outgoing link balance og vurdere, om profilen ser naturlig ud. For en liste med 20 domæner er det 2–3 timers gentagende arbejde.

Most of that work is pattern recognition against fixed criteria — exactly what a scoring algorithm handles instantly. The human judgement is only needed at the end, for the 3–5 domains that survive the hard filters.

Det meste af det arbejde er mønstergenkendelse mod faste kriterier — præcis hvad en scoringsalgoritme håndterer øjeblikkeligt. Den menneskelige vurdering er kun nødvendig til sidst, for de 3–5 domæner, der overlever de hårde filtre.

How it works Sådan fungerer det

The workflow Arbejdsgangen

01
Export from Ahrefs

Run a Batch Analysis in Ahrefs on the broker's domain list and export the CSV. The tool reads the exact Ahrefs export format — tab-separated, UTF-16, all columns auto-detected by name. No reformatting required.

Kør en Batch Analysis i Ahrefs på brokerens domæneliste og eksportér CSV'en. Værktøjet læser det præcise Ahrefs-eksportformat — tab-separeret, UTF-16, alle kolonner auto-detekteres efter navn. Ingen reformatering nødvendig.

Input Ahrefs Batch Analysis .csv export
02
Algorithmic scoring (V1)

Each domain is scored against 6 criteria derived from real iGaming link buying experience. Hard failures — near-zero traffic, extreme dofollow imbalance, PBN signals — push scores toward zero regardless of other metrics. Domains are ranked, filtered, and exportable to CSV.

Hvert domæne scores mod 6 kriterier fra reel iGaming link buying-erfaring. Hårde fejl — nær-nul trafik, ekstrem dofollow-ubalance, PBN-signaler — trækker scores mod nul uanset andre metrikker. Domæner rangeres, filtreres og kan eksporteres til CSV.

Output Scored and sorted domain list — approve / review / reject
03
Claude AI analysis (V2)

Domains that pass V1 scoring are sent to Claude via the Anthropic API. Claude assesses topical relevance to the destination site, geo fit, and whether the domain looks like a genuine editorial property or a guest post farm. It also recommends a balanced anchor text set and the most relevant destination URL for each placement.

Domæner, der består V1-scoring, sendes til Claude via Anthropic API. Claude vurderer topical relevans for destinationssitet, geo-match og om domænet ligner en ægte redaktionel side eller en guest post-farm. Det anbefaler også et afbalanceret anchor text-sæt og den mest relevante destinations-URL for hvert placement.

API Anthropic Claude API
Output Topical verdict · anchor text suggestions · destination URL per domain

What the tool checks — and what it can't Hvad værktøjet tjekker — og hvad det ikke kan

The tool is honest about its own limitations. The criteria coverage panel inside the tool shows exactly which checks are automated, which are partial, and which require a manual verification — so you know precisely when to trust the output and when to open Ahrefs yourself.

Værktøjet er ærligt om sine egne begrænsninger. Kriteriedækningspanelet inde i værktøjet viser præcis, hvilke tjek der er automatiserede, hvilke der er delvise, og hvilke der kræver manuel verifikation — så du ved præcis, hvornår du kan stole på outputtet, og hvornår du selv skal åbne Ahrefs.

Architecture

Two versions, one workflow To versioner, én arbejdsgang

The tool is built in two layers. V1 is the algorithmic baseline — fast, deterministic, and explainable. V2 layers Claude on top to handle the judgements that metrics alone can't make.

Værktøjet er bygget i to lag. V1 er den algoritmiske baseline — hurtig, deterministisk og forklarlig. V2 lægger Claude ovenpå til at håndtere vurderinger, som metrikker alene ikke kan foretage.

V1 — Algorithmic

Hard criteria, instant output

Scores every domain against 6 measurable criteria. No API required — runs entirely in the browser on the Ahrefs export.

  • DR, traffic, dofollow % thresholds
  • Link balance ratio with tiered deductions
  • PBN signal detection (4 independent checks)
  • Geo / ccTLD mismatch flagging
  • Configurable thresholds — adjust to any vertical
  • Export to CSV for handoff or reporting
V2 — Claude AI

Topical reasoning and anchor recommendations

Sends passing domains to Claude with destination site context. Handles the qualitative layer that numbers can't capture.

  • Topical relevance assessment per domain
  • Guest post farm vs editorial site judgement
  • Geo fit to target market
  • Balanced anchor text set (branded, keyword, partial, generic)
  • Recommended destination URL per placement
  • Optional GSC data input for keyword-aware anchors
